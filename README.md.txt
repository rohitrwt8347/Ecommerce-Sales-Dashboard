# Ecommerce Dashboard

## Project Overview

This project analyzes ecommerce sales data and presents the results through an interactive Power BI dashboard. The goal is to understand sales performance, revenue trends, profit, products, and regional performance.

## Tools Used

- Power BI
- Microsoft Excel
- SQL

## Key Features

- Total sales and KPIs
- Monthly sales trend analysis
- Product and category performance
- Regional sales comparison
- Interactive filters and slicers
- Data cleaning and transformation

## Key Insights

- [Total Revenue - 25.4M]
- [Total Customers - 50K]
- [Total Items Sold - 300K]


## Project Files

- `powerbi/` — Power BI dashboard file
- `screenshots/` — Dashboard screenshots
- `sql/` — SQL queries used for analysis
- `excel/` — Excel analysis files(sry didn't add)

## How to Open the Dashboard

1. Download the `.pbix` file from the `powerbi` folder.
2. Install Power BI Desktop.
3. Open the `.pbix` file in Power BI Desktop.
4. Use the filters and slicers to explore the dashboard.
